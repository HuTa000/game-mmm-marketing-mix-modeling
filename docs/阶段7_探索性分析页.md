# 阶段 7：探索性分析页（交互式 EDA）

> 目标：把"这份数据支不支持做归因"变成**可交互、可对任意数据源复现**的诊断，
> 而不是只给几张内置数据的静态截图。

---

## 1. 这一页解决什么问题

阶段 1 的 EDA 是**脚本**：读内置数据、出 5 张 PNG、打印结论文本。
它能证明"我做过 EDA"，但不能回答面试官最关心的那句：

> "如果给你一份**我们公司的真实投放数据**，你怎么判断它能不能做归因？"

阶段 7 把 EDA 重做成**应用内的诊断引擎**：

| 阶段 1（脚本） | 阶段 7（页面） |
|---|---|
| 只处理内置模拟数据 | 内置数据 **与** 用户上传的 CSV 走同一套算法 |
| 固定 5 张 PNG | 实时计算、可缩放悬浮的交互图 |
| 结论打印在终端 | 结论汇总成一张「支持度评分卡」，置顶展示 |
| 无法验证对错 | 每个判据都有**人造数据 + 已知答案**的离线断言 |

## 3. 五个诊断：每个都对应一个业务问题

### 3.1 趋势与节律 —— "收入为什么忽高忽低？"

**算法**：收入与总花费同轴对照（大促周标注）+ STL 分解成 趋势/季节/残差。

**关键实现**：STL 要求 `n > 2·period`。上传 40 周数据时按 `period = (n-1)//2` 自动缩短，
并通过 `period_used` 与 `note` **如实告知用户"季节项是按 19 周周期估的"** ——
而不是静默失败或静默给一个不可信的 52 周周期。

**实际结果**（内置数据）：季节项解释 **51.0%** 的收入方差，与阶段 1 完全一致。

→ 用途：**给"必须建模季节性"做数据辩护**。不建模季节，模型会把"春节收入自然高"
误读成"春节广告特别有效"，ROI 虚高。

### 3.2 渠道可分离性 —— "5 个渠道能被分开归因吗？"

**算法**：相关系数矩阵 + VIF（方差膨胀因子）。

**自己实现 VIF 而不是调 statsmodels**，原因有两个：

1. `variance_inflation_factor` 在**完全共线/常数列**上会返回 `inf` 或 `NaN`，
   不同版本对缺失值与常数项的处理还不一致；
2. 自研版本在自测里与 statsmodels **数值等价**（断言误差 < 1e-6），
   同时行为完全可控 —— 既拿到权威性，也拿到确定性。

**★ 踩过的坑（写进代码注释，防止回退）**：

> 初版用 `np.isfinite` 过滤 VIF 值时，把 `inf` 也一并滤掉了 ——
> 结果**最严重的"完全共线"被排除在 `max_vif` 之外**，判定反而显示"健康"。
> 现在 `inf`（完全共线）、`NaN`（渠道无变异）、有限值分三类统计，
> 并在自测里用 `tiktok = facebook + google` 的数据固化这条断言。

**实际结果**：最大 VIF = **1.10**，渠道间最大 |相关| = 0.288 → 判定"渠道可分离 ✓"。

### 3.3 广告滞后效应 —— "今天投的广告，几周后才见效？"

**算法**：互相关函数 `corr(spend_{t-k}, revenue_t)`，k = 0…8。

**改进**：除了峰值滞后，还算**半衰滞后**（|r| 从峰值跌到一半所需的周数），
用它推断 Adstock 窗口：

```
l_max = clip(round(median_half_lag) + 4, 6, 12)
```

下限取 6 是**工程约定**（几何衰减的尾巴需要足够预热窗，窗口太短会把上期残留
算到当期），这一点在代码注释里明确标注为"约定"而非"数据结论"，不混淆两者。

**实际结果**：l_max = **6**，与阶段 2 建模时的实际设定一致。
附带近似 95% 显著性带 `±1.96/√n` —— 带内的波动不可当真。

### 3.4 花费-收入与饱和 —— "加钱还有用吗？"

**这是本页最有价值的一段**，因为它演示了 MMM 最难缠的问题。

**做法**：两条曲线对照。

- **毛关系（灰）**：直接画 `渠道花费 → 收入`，加 LOWESS 平滑。
- **净关系（紫）**：先用 OLS 把 `其他渠道 + 控制变量 + 趋势 + 季节`
  的影响剔除（partial residual / 偏回归图），再看剩余部分。

**判据**：对净数据拟合二次式，算端点斜率比 `flatness = s_high / s_low`：

| flatness | 判定 | 业务含义 |
|---|---|---|
| < 0.75 | 递减 | 已进入饱和区，继续加钱效率下降 |
| 0.75 ~ 1.33 | 近似线性 | 边际回报基本恒定 |
| > 1.33 | 递增 | 仍在 S 形曲线的**超线性段**，拐点还在观测范围之外 |

**实际结果**：控制后 5 个渠道中 **4 个判定为"递增"**，中位端点斜率比 1.47。

这个结论一开始看起来像 bug（"阶段 2/3 明明说边际递减，这里怎么是递增？"），
核查数据生成机制后确认**是数据本身如此**：

```
TRUE_GAMMA_FRAC = {facebook: 2.5, google: 2.2, tiktok: 1.6, youtube: 1.8, kol: 2.8}
```

半饱和点被刻意设在**平均花费的 1.6~2.8 倍**，所以观测到的花费区间
（大致 0~3 倍均值）落在 Hill 曲线的**左半段**，数学上就是 `shape ≈ ad^(1+s)/κ^s`，
弹性 `1+s > 1`，天然上凸。

**这个发现与阶段 3 完全自洽**：正因为还没有饱和，预算优化的最优解才会
**全部卡在约束边界上**（阶段 3 记录的"硬边界下最优解全卡角点"现象）。

页面的结论文案因此写成分支式，而不是硬说"应该用饱和曲线"：

> ④ **不可**把这段递增外推到大预算（区间外才出现饱和拐点）；
> ② 线性模型会低估这段回报，仍需 Hill 这类能刻画超线性段的函数；
> ① 预算优化时最优解容易顶到约束上界。

**交叉验证彩蛋**：若 `outputs/reports/stage3_marginal_roi.csv` 存在，
页面会并排展示「EDA 净末段斜率」与「阶段 3 贝叶斯模型的边际回报」的排序对照
（Spearman ρ）—— 两条完全独立的路径得到一致的渠道排序，
说明结论不是某个模型"捏"出来的。

### 3.5 可识别性与数据质量 —— "哪一列缺少信息量？"

**两件事**：

1. **逐列体检**：CV（变异系数）、零值占比、峰值/均值倍数。
   CV < 0.10 意味着该渠道投入过于平稳 —— 数据里没有任何"变动"能用来估计它的效果。

2. **方向稳定性（移动块自助法）**：
   对 `收入 ~ 渠道 + 控制变量` 跑 OLS，再用**移动块自助法**重抽 240 次
   （块长 6 周），看每个渠道系数的抽样分布。

   为什么不用普通 iid 自助法：广告数据有自相关，独立重抽会破坏周与周的依赖结构、
   把区间估窄（假显著）。整块重抽保留了局部时间结构。

   判据：`P(系数>0) ≥ 0.975` 且区间不跨 0 → 方向可信；跨 0 → 无法确认方向。

**实际结果**：5 个渠道全部 `P(系数>0) ≥ 0.996`，区间不跨 0 → 方向可信。

## 4. 结论卡片：八项检查的评分逻辑

| 检查项 | 权重 | pass | warn | fail |
|---|---|---|---|---|
| 历史长度 | 1.0 | ≥104 周 | 52~104 | <52 |
| 渠道数量 | 0.6 | ≥3 | 2 | <2 |
| 渠道共线性 | 1.6 | VIF < 5 | 5~10 | >10 或 ∞ |
| 渠道投入的变动幅度 | 1.6 | 最小 CV ≥ 0.10 | 0.02~0.10 | <0.02 |
| 投放稀疏程度 | 0.8 | 最大零投占比 < 30% | 30~60% | ≥60% |
| 收入本身的波动 | 0.6 | CV ≥ 0.05 | 0.02~0.05 | <0.02 |
| 控制变量 | 1.0 | ≥3 个 | 1~2 个 | 0 个 |
| 渠道效应方向稳定性 | 1.6 | 全部不跨 0 | — | 有负系数或过半跨 0 |

**权重设计原则**：可识别性类问题（共线性、渠道变异、方向稳定性）权重最高，
因为它们是"再复杂的模型也救不回来"的一类；数据规模与质量问题次之。

综合判定：`0 fail 且 ≤2 warn → 支持归因`；`0 fail → 基本支持`；
`1 fail → 结论存疑`；`≥2 fail → 不建议直接归因`。

**内置数据实测：8 项全 pass，评分 100 / 100。**

## 5. 四个设计决策与理由

### 5.1 全部图表现算现画，不复用阶段 1 的静态 PNG

静态 PNG 只对应内置数据，用户上传 CSV 后完全失效。现算现画则两个数据源都覆盖。
代价是必须把算法从"边算边画"重构成"算数据 / 画图分离" —— 这正是 `eda.py`
不依赖 Streamlit 的原因。

### 5.2 结论卡片放在最上面

业务方关心"能不能开工"，而不是先看八张图。论证过程放在下面，想看细节的人往下翻。
每个区块固定三段式：**业务问题 → 图 → 这张图告诉我们什么（含该怎么用）**。

### 5.3 缓存键用数据指纹，不对 DataFrame 做哈希

```python
@st.cache_data
def cached_eda(fingerprint, _df, ...):   # 下划线前缀 → Streamlit 不哈希 _df
```

- 每次交互重跑脚本时不会重新 pickle 整张表（快）；
- 键里含指纹，换了数据**一定**不会命中旧结果（正确性优先于性能）。

### 5.4 用 Plotly 而非 matplotlib

窄屏适配的两个关键：`responsive: True` + `ui.FULL_WIDTH` 的运行时签名探测。
多图布局用 `st.columns`（窄屏自动堆叠为单列），而不是 `make_subplots` 多列
（窄屏会被压扁）。

| 场景 | 结果 |

| 某渠道常数非零（低 CV） | 正常，结论降级为 warn |

离线断言（`app/selftest_core.py`，T22~T27）：

- **VIF 与 statsmodels 数值等价**（误差 < 1e-6）
- **完全共线 → VIF = ∞**（而不是被静默忽略）
- **常数列 → VIF = NaN**
- **已知滞后 3 周 → 峰值定位准确**
- **凹数据（幂 0.4）→ 判定递减；凸数据（幂 2.2）→ 判定递增**
- **纯季节数据 → 季节项解释 > 85% 方差**
- **40 周数据 → 周期自动缩短并回报 `period_used`**
- **块自助法区间不跨 0、索引长度与范围正确**
- **★ 遗漏变量偏差实证**：同一份数据，控制 `trend` 后系数误差 < 0.05；
  故意不控制时误差跳到 0.18 —— 这条断言把"内生性"从口头概念变成了可回归的代码
- **完全共线数据 → 结论卡片出现硬伤**（不再误判为健康）
- **内置数据端到端**：相关 0.899 / VIF 1.10 / 季节 51.0% / l_max 6，
  与阶段 1、2、3 的历史结论逐项对齐

## 7. 面试可讲的三个点

1. **"我不只看相关，我做了偏回归。"**
   单渠道散点在这份数据上显示"越花钱收入越高、涨得越快"（像规模效应），
   控制其他因素后才看清真实形态。这个对照图本身就是"内生性"最好的教具。

2. **"我发现数据在 Hill 曲线的超线性段，并解释了它为什么与优化结果自洽。"**
   半饱和点是均值的 1.6~2.8 倍 → 观测区间在左半段 → 边际回报递增 →
   所以优化最优解会顶到约束上界。**诊断结论与优化结论互相印证**，而不是各说各话。

3. **"我的诊断有回归测试。"**
   VIF 与 statsmodels 对照、已知滞后/已知形态的人造数据断言、遗漏变量偏差的正反例 ——
   一共 24 条新断言。算法改动若导致诊断退化，测试会立刻报出来。
