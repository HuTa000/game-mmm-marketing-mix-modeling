# 阶段 0 学习笔记：MMM 核心参数逐个讲透

> 目的：让你在面试时能解释**每个参数为什么这么设**，而不是"教程这么写的"。

---

## 一、先建立直觉：MMM 在做什么？

想象你是一家手游公司的市场负责人。每周你在 5 个渠道花钱，每周游戏收入都在变。
老板问："**这 100 万收入里，有多少是 Facebook 带来的？**"

问题是：你永远看不到"如果不投 Facebook 会怎样"——这个反事实世界不存在。
MMM 的做法是：**用数学结构去近似这个反事实**。

```
游戏收入 = 基线（自然增长 + 老玩家付费 + 季节性）
         + Facebook 带来的    ← 我们要估的
         + Google 带来的      ← 我们要估的
         + TikTok 带来的      ← 我们要估的
         + ...
         + 噪声
```

**贝叶斯版本的价值**：不说"Facebook 带来 23 万"，而说"**有 94% 的把握，Facebook 贡献在 18~29 万之间**"。决策者要的就是这个区间。

## 二、Adstock（广告滞后效应）：为什么上周投的广告这周还有用？

### 业务问题
你周一投了一条 TikTok 广告，用户当天没下载，周三刷到第二次才下载。
**如果把周三的下载全算在周三的花费上，就会高估周三、低估周一。**

### 数学形式
几何 Adstock：本期"有效广告量" = 本期投入 + 上期残留 + 上上期残留...

```
A_t = x_t + λ · A_{t-1}
     ↑本期   ↑上一期的残留效果
```

- `λ`（decay，衰减率）：取值范围 0~1
  - `λ = 0` → 广告效果当期就消失，下周完全没影响
  - `λ = 0.5` → 上周的效果这周还剩一半（半衰期 1 周）
  - `λ = 0.9` → 效果非常持久，一个月后还有影响（品牌广告常见）
- `l_max`（最大滞后周数）：**决定"追溯到多久以前"**
  - `l_max = 8` → 只看过去 8 周，第 9 周前的效果当 0
  - 设太小 → 漏掉长期效果，高估短期；设太大 → 计算慢，且尾部噪声大
  - **经验值**：周数据用 6~12 周；效果型广告取小，品牌型取大

### 具象例子（λ = 0.5）
| 周次 | 当期投入 | 上期残留 | 本周有效广告量 |
|---|---|---|---|
| W1 | 100 | 0 | 100 |
| W2 | 100 | 100×0.5 = 50 | 150 |
| W3 | 100 | 150×0.5 = 75 | 175 |
| W4 | 100 | 175×0.5 ≈ 88 | 188 |
| W5 | **0**（停投） | 188×0.5 ≈ 94 | **94** ← 停投还有效果！ |

**这张表就是面试金句**："停投后收入不会立刻掉，因为广告有滞后效应——这正是 MMM 比简单 ROI 计算更准的原因。"

## 三、Saturation（饱和曲线）：为什么加预算效果会递减？

### 业务问题
TikTok 投 10 万拿到 1000 个新增用户，投 100 万能拿到 10000 个吗？
**不能。** 因为目标人群是有限的，投多了会重复触达同一批人。

### 数学形式：Hill 函数
```
f(x) = x^κ / (x^κ + γ^κ)
```
- `κ`（kappa / slope）：曲线"陡不陡"
  - `κ > 1` → S 型：**先慢后快再慢**（需要投到一定量才有效果，常见于需要多次触达的品牌广告）
  - `κ < 1` → 凸型：**一开始就快速见效，然后迅速递减**（常见于效果广告）
  - `κ = 1` → 标准 Michaelis-Menten 形式
- `γ`（gamma / 半饱和点）：**达到一半最大效果所需的花费量**
  - 这是最有业务含义的参数！假设 γ = 50（万元），意味着"花 50 万时，效果达到理论最大值的一半"
  - 如果某渠道当前周花费只有 5 万，说明**远没饱和，加预算空间大**
  - 如果当前花费是 200 万，说明**已经严重饱和，加预算几乎没用**

### 具象例子
| 渠道 | 当前周花费 | 估出的 γ | 业务解读 |
|---|---|---|---|
| Facebook | 8 万 | 30 万 | 远未饱和 → **加预算有效** |
| Google | 14 万 | 12 万 | 接近饱和 → **维持或微调** |
| YouTube | 6 万 | 4 万 | 已过饱和点 → **削减部分预算** |

**这张表就是阶段 3 预算优化的直接依据。**

### 饱和曲线的巨大价值：定位成本黑洞
```
效果
  ↑
  │        ┌──────  ← 饱和区：每加 1 元几乎没产出
  │      ╱
  │    ╱   ← 高效区：每加 1 元产出最高
  │  ╱
  │╱ 
  └────────────────→ 花费
```
面试时说："MMM 的价值不是告诉我历史 ROI，而是告诉我**下一个 100 万该投哪**——这需要知道曲线的斜率，而不是平均 ROI。"

## 四、yearly_seasonality（年度季节性）

### 业务问题
游戏收入天然有波动：寒假/春节是高峰，工作日和周末也不同。
**如果不把这个提出来，模型会把"春节带来的收入暴涨"错误归因给"春节期间的广告投放"，导致 ROI 虚高。**

### 数学形式
用**傅里叶级数**拟合周期波动：
```
season(t) = Σ [a_k · cos(2πkt/52) + b_k · sin(2πkt/52)]
                k=1..K
```
- `yearly_seasonality=2` → K=2，用 2 组正弦余弦波（共 4 个参数）拟合全年波动
- **K 怎么选**：K 越大越灵活，但容易过拟合
  - K=1：只有一个大波峰（如"夏季高、冬季低"）
  - K=2：能刻画"双峰"（如春节 + 暑假）
  - K=3~4：能刻画出更细的季节形态
  - **游戏出海建议 K=2~3**（春节/暑假双高峰 + 圣诞节）

### 具象例子
手游《XX战争》在东南亚：3 月斋月、6 月学校假期、12 月圣诞三个高峰。
K=3 就能大致刻画出这种多峰形态。

## 五、控制变量（control_columns）：MMM 难点的正面回应

这是**面试必问的深度问题**，你在阶段 1/2 一定要准备。

### 核心难点：遗漏变量偏误（Omitted Variable Bias）
假设你不知道某个渠道在"大促周"和"品牌联名活动"时加投，
而大促周本身收入就高 → 模型会**把大促的收入归功于广告**，ROI 虚高。

### 缓解手段
把那些"同时影响投放和收入"的因素作为控制变量放进模型：
- `control_columns`：例如竞品活动强度、本作版本更新、IP 联名事件、节假日 dummy
- `add_events()`：PyMC-Marketing 专门用于加入"事件/异常"的方法

## 六、采样参数（MCMC 相关）

| 参数 | 通俗解释 | 怎么调 |
|---|---|---|
| `draws` | 每条链从后验里抽多少个样本 | 探索用 500~1000，正式报告用 1000~2000 |
| `tune` | 预热步数（让采样器"热身"找到合适步长） | 一般等于或略大于 draws |
| `chains` | 独立运行几条链 | **≥2**，用于 R-hat 检查；正式 ≥4 |
| `nuts_sampler` | 采样后端 | `"numpyro"`（纯 Python，Windows 友好、快）、`"nutpie"`（Rust，最快）、默认 pytensor |
| `random_seed` | 随机种子 | **必设**，保证可复现 |

### 为什么采样慢？
NUTS 是"梯度引导的自适应采样"，每一步都要算整个模型的梯度。
模型复杂（渠道多、l_max 大）+ 数据长 → 每一步都贵。
**这就是阶段 8 要做「快速模式」和缓存的原因。**

## 七、诊断指标：怎么判断结果可信？

### 1. R-hat（潜在尺度缩减因子 / Gelman-Rubin 统计量）
- **它在问**：我跑了 2~4 条独立的链，它们给出的答案一致吗？
- **判定**：`R-hat < 1.01` 可信；`> 1.1` 明显不收敛
- **通俗类比**：让 4 个人独立解同一道题，答案都在 2.00 附近 → 可信；一个人答 2，一个人答 50 → 没收敛
- **不达标怎么办**：增加 draws/tune、简化模型、换个采样后端、检查先验是否太离谱

### 2. ESS（有效样本量，Effective Sample Size）
- **它在问**：我的 1000 个样本里，真正"独立且信息量足"的有几个？
- **为什么不是 1000**：MCMC 样本之间有自相关，相邻样本信息重复
- **判定**：`ess_bulk > 400` 一般可接受；`> 1000` 很好
- **不达标怎么办**：增加 draws、对参数重新参数化、换后端

### 3. Trace（轨迹图）
- **看什么**：每条链的轨迹是**像毛毛虫一样随机游走、且几条链混在一起**吗？
- **好**：链之间交织，像白色噪声
- **坏**：链各走各的（没收敛）、出现阶梯/平台（卡住了）、尖峰（多峰后验）

### 4. 后验预测检验（Posterior Predictive Check）
- **看什么**：模型"生成"的收入 vs 真实收入，分布像不像？
- **怎么算**：`mmm.sample_posterior_predictive(X)` 然后画对比图
- **业务解读**：如果模型连历史都拟合不好，它的 ROI 数字就不可信

## 八、MMM 的四大难点（面试高频）

| 难点 | 通俗解释 | 后果 | 缓解手段 |
|---|---|---|---|
| **内生性** | 你是"因为预期会大卖"才加投，还是"加投导致大卖"？因果方向不清 | ROI 高估 | 加控制变量；用 lift test 校准；讨论反向因果 |
| **渠道共线性** | Facebook 和 Google 总是一起加投，模型分不清谁在起作用 | 后验很宽，结论不稳定 | **看 VIF**；合并相似渠道；用 **lift test / 地域实验**提供先验 |
| **遗漏变量** | 漏掉的促销/版本更新/竞品动作 | 偏高估广告效果 | 尽量加控制变量；做敏感性分析 |
| **可识别性** | 如果所有渠道费用都同步变动，模型在数学上**无法区分**它们 | 参数不可识别 | 需要花费有独立波动；用小规模实验（geo-lift）补充 |

**缓解手段的黄金组合**：**MMM + 增量实验（Geo Lift / Randomized Test）**
- MMM 提供全局视角和跨渠道可比性
- 实验提供因果锚点，用作 **先验（prior）** 去校准 MMM
- PyMC-Marketing 的 `add_lift_test_measurements()` 就是干这个的

> **面试金句**："MMM 不是因果推断的终点，它是和实验互补的工具。我会用实验结果给 MMM 的先验做校准，这样既保留了 MMM 的全局性，又引入了实验的因果可信度。"

## 九、快速自检清单（你能答上来吗？）
