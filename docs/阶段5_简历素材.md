## 一、技术版（投算法 / 数据科学 / 机器学习岗）

**游戏出海广告效果分析：贝叶斯营销组合建模与预算优化**　|　个人项目　|　Python

- 独立搭建**贝叶斯 MMM** 全链路（Adstock 广告残留 + Hill 饱和曲线），使用 **PyMC / PyMC-Marketing**
  定义层次模型，**NumPyro（JAX）** 后端完成 NUTS 采样，覆盖从数据构造、EDA、建模、诊断到预算优化的 6 个阶段。
- **设计带真值标注的仿真数据集**（156 周 × 5 渠道 × 4 控制变量），用于定量验证模型的可识别性与参数回收能力——
  这在真实数据上无法做到，是本项目区别于「跑通示例」的核心。
- **采样收敛与参数回收双达标**：21 个参数中 R-hat > 1.01 的为 **0 个**、发散样本 **0 / 6000**、
  最小有效样本量 ESS **2815**；5 个渠道的 Adstock 衰减率 **4 个精确命中真值**（误差 < 0.005）。
- **定位并修复 3 个静默失效缺陷**，包括：库默认 `target_scale=max` 导致截距被迫为负（改为 `mean` 后截距由 −0.14 修正为 +0.43）、
  `channel_scales` 因 `getattr` 回退到 1.0 导致优化器返回「五渠道完全等分」的假解（修复后迭代次数由 1 提升至 57）、
  控制变量未显式传入导致被静默忽略。
- **设计 D0→D3 四档对照实验量化渠道可识别性上限**：证明在渠道花费高度共动（最大相关 0.87）时 ROI 排序一致性仅 −0.10，
  而通过注入独立脉冲（相关降至 0.24）可提升至 **+1.00**——结论是「归因能力由数据设计决定，而非算法」。
- **用 SciPy SLSQP 求解约束预算优化**，并对 59 组后验样本逐一重跑优化给出分配的置信区间；
  输出「弹性-收益曲线」量化调整幅度与收益的对应关系（±5% → +1.36%，±40% → +14.37%，无约束 → +75.73%）。

**技术栈**：Python · PyMC · PyMC-Marketing · NumPyro/JAX · ArviZ · pandas · NumPy · SciPy · statsmodels · matplotlib

## 二、业务版（投商业分析 / 增长分析 / 市场分析岗）

**游戏出海广告投放效果归因与预算优化分析**　|　个人项目　|　Python + 贝叶斯建模

- **背景**：游戏出海买量占收入比重大，但平台归因报表存在近因偏差与重复归因，无法回答「多加 100 万会发生什么」。
  选择**营销组合建模（MMM）**替代平台报表，从 156 周投放数据中分离 5 个渠道的真实贡献。
- **剔除混杂后给出可执行的渠道效率排序**：tiktok（ROI 2.50）> google（1.56）> kol（1.24）> facebook（1.07）> youtube（0.66），
  并以 **94% 可信区间**替代点估计——youtube 的区间上界仍低于 1，为「减投」提供了统计依据而非主观判断。
- **量化「钱该往哪挪」**：计算各渠道**边际回报**（每多投 1 元能拿回的金额），
  tiktok 3.16 元最高、youtube 仅 0.80 元（低于 1 即为亏损投放），直接指向调优方向。
- **在业务约束下求解最优分配**：明确指出「无约束的数学最优解 = 全部预算押给单一渠道」不可执行
  （涉及团队编制、账号权重、平台关系刚性），转而交付**±20% / ±40% 等弹性档位下的收益对照**
  （±20% → +6.13%、±40% → +14.37%），让业务方按可接受的调整幅度自主决策。
- **输出一页纸决策报告**：把建模结果转化为结论、依据、风险提示与行动建议，
  并设计**数字白名单校验机制**（三级判定：精确 / 舍入偏差 / 无依据）拦截大模型编造数据，
  实测幻觉拦截率 100%，校验不通过自动降级为模板，保证报告不会输出错误数字。

**工具栈**：Python · 贝叶斯统计建模 · 约束优化 · 数据可视化 · 自动化报告

## 六、表述红线（面试被追问时不会翻车）

简历里的每一句话都可能被追问细节，**以下三类表述必须守好边界**：

| 不要说 | 应该说 |
|---|---|
| 「提升了 14.37% 的收入」 | 「**预期**媒体贡献提升 14.37%（模型估计值，94% CI 为 +638 万 ~ +728 万元）」 |
| 「证明了 tiktok 效果最好」 | 「在**带真值标注的仿真数据**上，模型估出的 ROI 排序与真值完全一致」 |
| 「模型非常准确」 | 「**排序准确**、参数部分回收；但存在基线/媒体结构性不可识别，绝对金额不可当财务口径」 |
| 「用 AI 生成报告」 | 「**数字由确定性代码提供**，大模型只负责组织语言，输出后逐数字白名单校验」 |
| 「做了因果分析」 | 「这是**观测数据上的统计推断**，定位为决策支持；因果验证需要 geo-lift / 停投实验」 |

**为什么必须这样说**：MMM 的资深面试官一定会问「你怎么知道模型是对的」。
如果你把仿真数据的结果说成真实业务结论，第一个追问就会露馅；
反过来，主动说明「我用仿真数据所以能验证参数回收」——这恰恰是**加分项**，因为它证明你理解 MMM 的根本困难。
