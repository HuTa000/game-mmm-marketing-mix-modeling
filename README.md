# 游戏出海广告效果分析 · 贝叶斯营销组合建模（MMM）

用**贝叶斯 MMM**（Marketing Mix Modeling）回答游戏出海业务的两个核心问题：

1. **归因**：过去 3 年、5 个投放渠道，各自贡献了多少收入？广告的滞后效应和边际递减有多强？
2. **决策**：下一季度 1,392 万预算该怎么重新分配？能多拿多少收入？这个结论有多可信？

结果最终打包为**可交互 Streamlit 应用**（阶段 6~10）与**自动化报告工作流**（阶段 4）。

| 亮点 | 具体结果 |

## 快速开始

```bash
# 1. 创建虚拟环境（Python 3.12 推荐；3.10+ 可用）
python -m venv .venv
.venv/Scripts/activate          # Windows
# source .venv/bin/activate     # macOS / Linux

# 2. 安装依赖
pip install -r requirements.txt

# 3. 按顺序运行（前一步的产物是后一步的输入）
python src/stage0_smoke_test.py     # 验证环境（约 1 分钟）
python src/stage1_eda.py            # EDA（约 30 秒）

python src/stage3_optimize.py       # 预算优化（约 3 分钟）
```

`g++ not available` 警告可忽略——那只是 pytensor 的探测提示，不影响采样。

## 核心方法

### 模型结构

```
y_t = 截距 + Σ_channel β_ch · Hill( Adstock(x_ch,t) ) + Σ_control γ_k · z_k,t + 季节项 + ε_t
```

- **Adstock（几何衰减）**：`A_t = x_t + λ·A_{t-1}` —— 广告效果跨期衰减，λ 越大"余温"越久
- **Hill 饱和**：`Hill(x) = 1 − κ^s / (κ^s + x^s)` —— 边际递减，s 为陡峭度、κ 为半饱和点
- **噪声**：`y ~ Normal(μ, σ)`，NUTS 采样（4 链 × 1500 draws，`target_accept=0.95`）

### 三个关键工程决策

1. **`target_scale` 必须设为 `mean`**（默认 `max` 会让截距被迫为负、媒体占比虚高到 145%）
2. **`channel_scales` 必须手动挂载**（库内部 `getattr(self, "_channel_scales", 1.0)` 会静默回退到 1.0，导致优化器返回无意义的"平均分配"）
3. **控制变量必须显式传入 `control_columns`**（否则被静默忽略）

三者的完整根因、复现代码与验证方法见 `docs/阶段3_预算最优分配.md` 与 `docs/阶段2_贝叶斯MMM建模与诊断.md`。

## 已知限制（诚实声明）

这些是 MMM 的**方法论固有局限**，不是实现缺陷。面试中被问到时应当主动说明：

1. **基线 vs 媒体结构性不可识别**
   `y = (基线+α) + (媒体−α) + ε` 恒成立 → 媒体贡献的**绝对量级**无法仅靠观测数据唯一确定。
   模型分解的媒体占比（约 57%）高于数据真值（约 54%）。**不影响渠道间的相对排序**，但绝对金额不可直接当财务口径。
   → 业界解法：geo-lift 实验、渠道暂停测试（pause test）。

2. **渠道间不可识别性由数据设计决定**
   若各渠道花费高度共动，模型无法分离各自贡献。本项目通过 **D0→D3 对照实验**量化了这一点
   （Spearman ρ：−0.10 → +0.70 → +0.60 → +1.00），结论：**需要足够的"独立脉冲"**（单渠道单独变动）。
   → 这既是数据采集建议，也是面试时最能体现"懂业务"的一点。

3. **优化结果的绝对收益口径偏乐观**
   优化窗口内媒体贡献含 **6.0% 的 carry-in 余温**（历史花费的衰减残留），不被本次分配控制。
   因此应关注 **"优化 vs 历史的差值"**，而非绝对总量。

4. **当前观测区间落在 Hill 曲线的超线性段**
   数据生成时半饱和点被设为平均花费的 1.6~2.8 倍，因此观测区间内
   **边际回报仍在上升**（阶段 7 诊断：控制其他因素后 4/5 渠道为"递增"）。
   这不是 bug，而是与本项目"优化最优解全卡约束角点"完全自洽的事实。
   → 含义：不能把这段递增外推到大预算；线性模型会低估这段回报，仍需 Hill 刻画。
   诊断细节见 `docs/阶段7_探索性分析页.md`。

## 数据说明

`src/data_generator.py` 生成**带真值标注**的模拟数据（156 周 × 5 渠道 × 4 控制变量）。
真值参数（真实 ROI / 衰减率 / 饱和点）记录在 `df.attrs` 与 `_true_*` 列中，
**仅用于验证模型的参数回收能力**，建模时不可使用。

设计上刻意注入了三个贴近真实的机制：
- **渠道断投周**（每渠道 3 窗 × 2 周，压到 5% 花费）→ 提供识别所需的外生变动
- **独立脉冲**（50 个随机周的单一渠道 3 倍加投）→ 打破渠道共动
- **差异化季节敏感度** + 大促脉冲 + 版本更新/竞品活动 → 制造需要控制的混杂
